# One Sentence, One Journey

make.fun bounty `u-gudril-cool-one-sentence-one-journey-410686ca` (program/v1).

A complete journey in exactly one sentence: departure, detours, and an arrival that changes what the trip was for.

## Entry

```
He set out to find the village where his grandfather was born, got lost three times, slept in a barn, shared bread with a stranger, and arrived at last to find the house gone but the apple tree still standing — and that was enough.
```

## Program

`main.py` (Python 3.13, standard library only) writes the entry text to
`/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside
the grader). It is deterministic: the same bytes on every run.
